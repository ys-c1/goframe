# 并发步进与串行等价性：条件与差异上界

本文给出两个结论及其证明，并由 `internal/parallel` 包与 `goframe parallelcheck` 命令可执行验证。

## 0. 记号与模型

一次帧步进被展开成有限的原子操作序列。每个操作是一次定点读-改-写：

```
op = (w, L, f)：worker w 读取位置 L 的当前值 x，写回 x + f(状态)
```

- 位置 `L = (实体 i, 字段 F)`，字段取 `velX / velY / posX / posY`，是写入集合的最小元素；
- worker 集合 `{1..W}`，实体按编号连续环分区，实体 `i` 的全部字段归唯一属主
  `owner(i) = floor(i·W/N)`；
- 一帧分为若干**阶段（phase）**，阶段之间有全局屏障；并发只发生在阶段内部；
- 所有数值为 Q16.16 定点整数，更新只有加法，故每个操作的增量满足
  `|δ| ≤ M`，`M` 是只取决于场景规模（冲量、重力、速度上界、耦合缩放位数）的常数；
- 记 worker `w` 在阶段 `p` 的写入集合为 `W(p,w) = { L | 存在 op=(w,L,·) 属于阶段 p }`。

串行执行 `S` 按一个固定全序依次应用全部操作；并发执行 `C` 在每个阶段内由各 worker
独立推进、阶段屏障处汇合。

## 1. 定理一（等价条件）：并发与串行末态逐字节相同，当且仅当每个阶段各 worker 的写入集合互不相交

**命题。** 对同一初态与同一操作集合，并发执行 `C` 与串行执行 `S` 末态相同的充要条件是，
对每个阶段 `p` 与任意 `w₁ ≠ w₂`：

```
W(p, w₁) ∩ W(p, w₂) = ∅。
```

这正是实体状态的**分区要求**：一个可写入位置在同一阶段内只能有一个属主 worker 对它写入。

### 充分性（条件成立 ⇒ 等价）

按阶段归纳。阶段 `p` 开始时，由归纳假设并发与串行处于同一状态 `xₚ`。

阶段 `p` 内任取两个操作 `op_a=(w_a,L_a,·)`、`op_b=(w_b,L_b,·)`。

- 若 `w_a ≠ w_b`，由写入集合不相交得 `L_a ≠ L_b`，即不同 worker 的操作写不同位置；
- 因此阶段内任意两个操作要么写不同位置（互不影响），要么属于同一 worker
  （同一 worker 内按程序序执行，与串行全序在该 worker 操作上的投影一致）。

于是阶段 `p` 的所有操作构成一个**偏序**：仅同一 worker 内部有先后约束，
跨 worker 操作之间 commute（作用位置不相交）。串行全序是该偏序的任意一个线性扩张，
并发调度是另一个线性扩张。对只含定点加法、且作用位置不相交的交换操作，
任意两个线性扩张的逐位置结果相同：

```
xₚ₊₁[L] = xₚ[L] + Σ_{op=(·,L,δ)} δ，
```

求和顺序不影响定点加法结果。故阶段末态 `xₚ₊₁` 在两种执行下相同，归纳成立。 ∎

### 必要性（条件不成立 ⇒ 存在不等价的并发交错）

设阶段 `p` 存在位置 `L` 与 `w₁ ≠ w₂`，使 `L ∈ W(p,w₁) ∩ W(p,w₂)`，
即两个 worker 都对 `L` 执行读-改-写。真实协程里“读—算—写”不是原子的，
考虑如下交错（`base` 为进入阶段时 `L` 的值，`δ₁,δ₂` 为两次更新的增量）：

```
w1: 读 base        w2: 读 base
w1: 写 base+δ₁     w2: 写 base+δ₂      ← w2 覆盖 w1，δ₁ 丢失
```

并发末态 `L = base + δ₂`，而串行末态 `L = base + δ₁ + δ₂`。
只要 `δ₁ ≠ 0`（实验中耦合冲量非零），两者必然不同。 ∎

`internal/parallel` 的确定性交错器（`RunInterleave`）用“读半轮 + 写半轮”精确复现
这一交错；真实 goroutine 执行器（`RunParallel`）在阶段执行前用 `phaseDisjoint`
判定，条件不成立直接返回 `ErrSharedWrite`，拒绝产生带数据竞争的运行。

## 2. 定理二（差异上界）：不满足条件时，末态差异与共享写入次数成正比

**共享写入次数（按字段统计）。** 对位置 `L`，记 `K(L)` 为总写入次数、
`K_other(L)` 为非属主 worker 的写入次数。当 `L` 被两个及以上 worker 写入时
`L` 是共享位置，定义

```
S(L) = K_other(L)，          S = Σ_{共享位置 L} S(L)。
```

统计最小单位是字段位置 `(实体, 字段)`，不是整个实体；同一实体的四个字段分别计数。

**命题。** 设 `M` 为单操作增量绝对值上界，`L` 为单个位置在整段运行中的最大写入次数，
则并发末态 `x_C` 与串行末态 `x_S` 的 L1 原始单位距离满足

```
D ≔ Σ_loc |x_C[loc] − x_S[loc]| ≤ 2·M·S·L。
```

### 证明

把每个位置的末值写成“初值 + 全部作用于它的增量之和”。

- 串行：`x_S[L] = x₀[L] + Σ_{op∋L} δ_op^S`，每个增量按串行状态求值；
- 并发：`x_C[L] = x₀[L] + Σ_{op∋L 且未被覆盖} δ_op^C`，部分更新因覆盖丢失，
  且存活增量可能在不同状态下求值。

对任一位置逐项比较。一次非属主写入（共享写入）只可能造成两类偏差：

1. **覆盖丢失**：该写入本身被后到者覆盖，或它覆盖了属主的先到写入。
   一次丢失的更新使末值相差一个增量，绝对值 `|δ| ≤ M`；
2. **求值偏差**：增量若依赖运行时状态（如读速度快照），并发与串行读到的基值不同，
   两次求值之差满足 `|δ_C − δ_S| ≤ |δ_C| + |δ_S| ≤ 2M`。

位置 `L` 上有 `S(L)` 次非属主写入，每次贡献的偏差不超过 `2M`；
而偏差沿同一位置的后续 `K(L) ≤ L` 次读-改-写传播时，每次传播仍是一次有界加法，
累计放大不超过 `L` 倍。故

```
|x_C[L] − x_S[L]| ≤ 2·M·S(L)·L。
```

对全部位置求和：

```
D = Σ_L |x_C[L] − x_S[L]|
  ≤ Σ_L 2·M·S(L)·L
  = 2·M·L·Σ_L S(L)
  = 2·M·S·L。
```

`M`、`L` 只由场景规模决定，与分区数无关，因此 **`D` 与共享写入次数 `S` 成正比**：
`D = O(S)`。当 `S = 0` 时上界给出 `D ≤ 0`，即退化为定理一的充分性结论。 ∎

说明：`2·M·S·L` 是结构性的保守上界，实测 `D` 通常远小于它（日志表二同时给出两者）；
比例性结论 `D = O(S)` 不依赖这个保守因子，实验中固定场景、只改并发度时
`S` 单调增加且实测 `D` 同向增长。

## 3. 修复：把共享写入改成“私写 + 屏障 + 跨 worker 读”

朴素计划中源 worker 直接写目标实体的速度字段，跨分区即产生共享写入。
修复版（`BuildStaged`）把一帧拆成五个屏障阶段：

| 阶段 | 操作 | 写入位置 | 跨 worker 访问 |
|------|------|----------|----------------|
| 0 | 外部冲量 | 本实体速度 | 无 |
| 1 | 耦合冲量写入源实体私有发件箱 | 本源实体 outbox | 无 |
| 2 | 读前驱发件箱，落到本实体速度 | 本实体速度 | 只读前驱 outbox |
| 3 | 重力与位置积分 | 本实体字段 | 无 |
| 4 | 清空本实体发件箱 | 本实体 outbox | 无 |

每个阶段的写入集合按实体分区互不相交（条件成立）；跨 worker 的只有阶段 2 的**读**，
而读不进入写入集合、不违反定理一的条件。落盘（阶段 2）先于积分（阶段 3），
与朴素计划“冲量→耦合→积分”的串行顺序一致；发件箱清理独立成阶段 4，
避免与阶段 2 的跨 worker 读同阶段并存而构成真实数据竞争。
两种计划的串行末态逐字节相同（`TestSerialPlansByteIdentical` 守卫），
修复只改变调度与写入归属，不改变仿真语义。

## 4. 复现实验

```
go test -race ./...
go run ./cmd/goframe parallelcheck
```

输出三栏结果（并发度 / 末态哈希 / 差异与条件判定）、差异上界验证表、
按字段的共享写入统计表，并在 `artifacts/parallel_check.log` 存一份完整日志。
默认场景（N=12, T=16）的结论：

- W=1：`S=0, D=0`，条件成立；
- W=2：朴素 `S=64, D≈2.49e8`，条件不成立；修复版哈希等于串行；
- W=4：朴素 `S=128, D≈3.64e8`，条件不成立；修复版哈希等于串行；
- 三档并发度修复版末态哈希全部等于串行基准，且 `D ≤ 2·M·S·L` 全部成立。
