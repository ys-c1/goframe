# 重力 9.8 的定点量化误差：恒定加速度差 → 位移按帧数平方增长

本文证明：把重力常量 9.8 量化成二进制定点分子 `N/2^f` 后，量化误差 `δg`
在每一帧贡献**同一个恒定加速度差**；经速度、位置两次积分，第 `n` 帧的位移差为

```
Δy_n = δg · n(n+1)/2  ≈  (δg/2) · n²
```

即位移差随帧数**平方增长**，二次项系数就是 **`δg/2`**。据此给出落点容差 `ε`
能撑到的首次越界帧 `k`，并在**三档分子位数**下对**两条抛物轨迹**逐档给出
落点差、横向偏移、容差与首次越界帧。所有数字由 `cmd/projectile` 用
`math/big.Rat` 精确计算，`go test ./internal/projectile` 与
`python3 -I analysis/verify_gravity.py` 双重核对。

## 0. 结论速览

- 精确重力 `g* = 49/5 = 9.8`。三档定点（容差取 **ε = 0.1 世界单位**，
  题面未指定数值，此值为声明的给定容差，可用 `--tolerance` 改）：

| 档位 | 分子 N（位数） | δg（每帧加速度差，精确） | 二次系数 c=\|δg\|/2 | 首次越界帧 k（ε=0.1） |
|---|---:|---:|---:|---:|
| Q8.8  | 2509（4 位）  | `+1/1280` = 7.8125e-4 | `1/2560` = 3.90625e-4 | **16** |
| Q16.16（仓库现行） | 642253（6 位） | `+1/327680` = 3.05176e-6 | `1/655360` = 1.52588e-6 | **256** |
| Q32.32（升精度） | 42090679501（11 位） | `+1/21474836480` = 4.65661e-11 | `1/42949672960` = 2.32831e-11 | **65536** |

- 帧限满足 `k(k+1) > 10ε·2^f`；ε=1/10 时化为 `k(k+1) > 2^f`，三档恰好
  得到 **16 / 256 / 65536**。连续近似 `k ≈ √(2ε/|δg|) = 2^(f/2)`。
- 两条轨迹：A 低伸快弧参考落地帧 **n\*=61**，B 高抛长弧 **n\*=408**。
  - **A**：Q8.8 不过（Δ=1.4773），Q16.16 过（Δ=0.00577），Q32.32 过。
  - **B**：Q8.8 不过（Δ=65.18），**Q16.16 跑过第 256 帧即越界、落点 Δ=0.2546>0.1 不过**，
    Q32.32 过（Δ=3.89e-6）。长航程轨迹正是“几百帧后偏出一截”，需要提高分子位数。
- 同一帧处落点差严格满足 **Δ_Q8 = 256·Δ_Q16**、**Δ_Q16 = 65536·Δ_Q32**。

## 1. 模型与记号

- 内核 `internal/fixed` 为 Q16.16（分母 2^16）。本文把精度推广为任意小数位 `f`：
  一档常量记作 `g_f = N_f / 2^f`，其中 `N_f = round((49/5)·2^f)` 是整数**分子**，
  “分子位数”即 `N_f` 的十进制位数。
- 采用与 `internal/sim/sim.go` 完全相同的半隐式欧拉、`SubSteps=1`
  （`g.Div(FromInt(1))` 不产生额外舍入），y 轴向上：

```
v_y(n) = v_y(n-1) − g_f
y(n)   = y(n-1)   + v_y(n)          // 先更速度，再用新速度更位置
```

- 参考解用精确有理数 `g*=49/5` 走同一递推，因此唯一差别就是重力常量的量化，
  不混入任何乘法/截断噪声。初速度取整数，各档都能精确表示。
- 单位说明：以上以**一帧为一个积分单位**（内核原生约定，`h=1`）。若接真实秒长 `h`，
  把二次系数与帧限中的 `δg` 替换为 `δg·h²` 即可：`k ≈ √(2ε/(|δg|h²))`。
  例如 60 Hz（h=1/60）下 Q16.16 对 ε=0.1 的帧限约为 `256·60 ≈ 15360` 帧。

## 2. 证明：恒定加速度差 → 两次积分 → 平方增长

### 2.1 每帧一个恒定加速度差

三档的最近分子与误差为：

```
f=8  : N=2509,       g=2509/256       = 9.80078125,        δg = +1/1280
f=16 : N=642253,     g=642253/65536   = 9.8000030517578125, δg = +1/327680
f=32 : N=42090679501, g=N/2^32         ≈ 9.8000000000466,    δg = +1/21474836480
```

因为 `f=8,16,32` 都是 4 的倍数，`2^f ≡ 1 (mod 5)`，使得
`5N_f − 49·2^f = 1`，故三档统一有精确形式

```
δg_f = g_f − 49/5 = 1/(5·2^f) > 0.
```

积分器每帧都把**同一个** `N_f`（原始分子）加进 `v_y`，所以量化重力相对精确重力
在**每一帧贡献完全相同的加速度差 `δg_f`**——它不随帧变化，是常量。
三档都向上舍入，因此定点解下落得更快，位置差恒为负，下文统一取绝对值。

### 2.2 第一次积分：速度差线性增长

每帧速度累积一次 `δg`：

```
δv_n = n·δg.
```

### 2.3 第二次积分：位置差平方增长，系数 = δg/2

半隐式格式用第 `j` 帧的新速度积分位置，因此第 `n` 帧的位置差是各帧速度差之和：

```
δy_n = Σ_{j=1}^{n} δv_j = δg·Σ_{j=1}^{n} j
     = δg·n(n+1)/2.
```

展开：

```
δy_n = (δg/2)·n² + (δg/2)·n.
```

所以随帧数平方增长的主项系数就是

```
┌──────────────────────────────────────────────┐
│  c_f = |δg_f|/2 = 1/(10·2^f)  （单位/帧²）      │
└──────────────────────────────────────────────┘
```

精确离散式 `c_f·n(n+1)` 比纯平方近似多一个同系数的线性项 `c_f·n`；
几百帧时线性项相对平方项约为 `1/n`（n=256 时约 0.4%），但它正是下面
“连续近似 257 vs 离散首次越界 256”一帧之差的来源，不能随便丢。

`go test` 中的 `TestRawRecurrenceMatchesQuadraticLaw` 逐帧断言整数递推
`y_raw = 2^f(H0+VY0n) − N_f·n(n+1)/2` 与该式完全一致。

## 3. 给定落点容差能撑多少帧

定义落点容差 `ε`（世界单位），要求参考落地整数帧 `n*` 处的同帧位置误差
`|δy_{n*}| ≤ ε`。一般帧限（首次严格越界帧）为

```
k = min { n≥1 : |δg|·n(n+1)/2 > ε }.
```

连续主项给出常用估算：

```
N_max ≈ √(2ε/|δg|) = √(ε/c).
```

代入本题三档的精确 `δg=1/(5·2^f)`：

```
n(n+1)/(10·2^f) ≤ ε   ⇔   2^f ≥ n(n+1)/(10ε).
```

取声明容差 **ε = 1/10** 后 `10ε=1`，条件化简为漂亮的

```
n(n+1) ≤ 2^f   （容差内），    首次越界 k = min{n : n(n+1) > 2^f}.
```

由于三档 `f` 都是偶数，`2^(f/2)` 这一帧恰好越界、前一帧恰好不越界：

| 档位 | 容差 ε | k（首次越界） | Δ(k−1) | Δ(k) | 边界核对 |
|---|---:|---:|---:|---:|:---:|
| Q8.8  | 0.1 | **16**    | 15·16/2560 = 0.0937500000 | 16·17/2560 = 0.1062500000 | 0.09375 ≤ 0.1 < 0.10625 ✓ |
| Q16.16 | 0.1 | **256**   | 255·256/655360 = 0.0996093750 | 256·257/655360 = 0.1003906250 | 对称夹住 0.1 ✓ |
| Q32.32 | 0.1 | **65536** | 65535/655360 ≈ 0.0999984741 | 65537/655360 ≈ 0.1000015259 | 对称夹住 0.1 ✓ |

（Q16.16 连续近似因要求严格 `n>256` 会报 257；计入离散线性项后真实首次越界是 **256**。）

**超过帧限就要提高常量的分子位数。** 对需要跑到第 `M` 帧的轨迹，所需小数位满足
`f ≥ log2(M(M+1)/(10ε))`。例如轨迹 B 的 `M=n*=408`、ε=0.1：
`M(M+1)=166872`，而 `2^17=131072 < 166872 ≤ 2^18=262144`，故理论上 **f≥18**
即够（f=24 一档的首次越界帧为 4096）；在给定三档里就应从 Q16.16 升到 **Q32.32**。

## 4. 三档位数 × 两条抛物轨迹（逐行数据）

“落点差”取参考落地整数帧 `n*` 处两解的同帧位置误差模（重力误差只在竖直轴，

“横向偏移”**单列一列**为同帧 x 分量（恒 0）；另给“地面落点距”列，即比较各自

### 横向偏移为什么单列、以及两种“落点”口径

- **同帧横向偏移严格为 0**：水平初速度取整数，在三档下都被精确表示，水平方向又没有
  加速度误差，所以任意同一整数帧上 `Δx=0`（表中“横向偏移”列；测试
  `TestRawRecurrenceMatchesQuadraticLaw` 守护）。这一列单列，正是为了把“重力量化误差
  只沿竖直轴、不产生同帧横向漂移”这件事点明。
- **插值地面落点距（射程差）非零**：重力偏差改变落地时刻，`g_f` 偏大 → 更早触地 →
  正 `vx` 下落点偏左，于是比较“各自真正落地点”时得到 `ΔX = vx·Δt_land`（带符号的
  `ΔX` 分别为 A：−4.4003 / −0.01719 / −2.62e-7，B：−9.7463 / −0.03808 / −5.81e-7），
  其绝对值即表中“地面落点距”。
- 两种口径的容差结论可能不同，必须分清：平方定律与“首次越界帧”核对的是**同帧状态差**
  `Δ(n)`，故 B/Q16 在第 256 帧中途越界、在 n\*=408 处 Δ=0.2546>0.1 判**不过**；
  而**最终地面落点**的射程距因落地时刻平移被补偿，只有 0.0381≤0.1。题目要求与越界帧
  一并核对的“落点容差”采用前者（与证明同一个量），后者作为独立一列保留，避免歧义。

## 5. 三档落点差逐档比对

在同一条轨迹的同一参考帧 `n*` 处，落点差严格正比于 `|δg|`，与轨迹初值无关：

```
Δ_Q8  / Δ_Q16  = 2^16 / 2^8  = 256
Δ_Q16 / Δ_Q32  = 2^32 / 2^16 = 65536
```

- 轨迹 A（n\*=61）：1.4773437 → 0.0057709（恰 ÷256）→ 8.8057e-08（再 ÷65536）；
  横向偏移 −4.4003 → −0.01719 → −2.62e-07，单调缩小。
- 轨迹 B（n\*=408）：65.1844 → 0.25463（恰 ÷256）→ 3.8853e-06（再 ÷65536）；
  横向偏移 −9.7463 → −0.03808 → −5.81e-07，同样单调缩小。
- 越界帧与容差一并核对：判定恒等于 `Δ(n*) ≤ ε`，也等价于 `n* < k`
  （见 `TestPassMatrixAndConsistency`）。故 A 在 Q16.16 容差内、B 在 Q16.16 越界，
  B 必须升到 Q32.32；Python 独立核对脚本对以上每一条都重新验算并全部 PASS。

## 6. 摩擦与弹性要不要同样处理

**一句结论：摩擦系数 μ 与弹性恢复系数 e 都是无量纲乘数、不经历重力这样逐帧两次积分的平方累积，通常沿用 Q16.16 并按各自容差做一次灵敏度/边界测试即可，不必像长程落点的重力那样专门提高分子位数——唯一需要留意的是，若把动摩擦建成恒定滑动减速度，它在连续滑动段内同样满足 `δa·n(n+1)/2`，但滑动一般很快终止、累积不到几百帧，而 e 只在碰撞瞬间乘速度、误差按（往往还几何衰减的）碰撞次数而非帧数传播。**
