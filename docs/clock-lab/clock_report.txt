R= 10 帧: before(t=1040ms,d=0ms) -> rollback(t=1050ms,d=100ms) -> after(t=1060ms,d=100ms)；上界 0≤d≤100ms=RΔ
R=100 帧: before(t=1040ms,d=0ms) -> rollback(t=1050ms,d=1000ms) -> after(t=1060ms,d=1000ms)；上界 0≤d≤1000ms=RΔ

四、上界
  钟差: 0 ≤ m(t)-w(t) ≤ (Σ_j R_j)Δ，单次回拨 ≤ RΔ（10/100/1000ms）
  帧号差(同相位): F_fixed-F_wall = 截至 t 的回拨累计 S(t)，故 ≤ ΣR_j（本实验=R）
  帧号差(计入一帧内提交滞后): |差| < ΣR_j + 1
  修复方案自身滞后: 0 ≤ m(t)-nΔ < Δ，即 lag/Δ ∈ [0,1)，严格低于一帧；累计回退 D_fixed=0
