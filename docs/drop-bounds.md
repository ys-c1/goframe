# 指令丢弃的偏差上界与保留策略

本文给出两条定理及其证明。定理 1 说明丢弃策略的偏差上界等于被丢冲量之和，
且与丢弃时机无关；定理 2 说明按冲量大小优先保留（TopK）在给定容量下最小化该上界，
并给出保留容量 K 与阈值 τ 的精确关系。

## 1. 记号与模型

仿真内核（`internal/sim`）是离散时间线性系统。记第 t 帧开始时所有实体的
速度、位置堆叠向量为 v_t、x_t（定点 Q16.16，线性运算中无截断误差）。
一帧内先施加本帧保留的冲量，再做一次积分（SubSteps=1；多子步只是把同一冲量
线性分摊，结论不变）：

```
v_{t+1} = v_t + p_t
x_{t+1} = x_t + v_{t+1} = x_t + v_t + p_t
```

其中 p_t 是本帧**实际施加**的冲量向量（未保留的指令不出现）。

设完整指令流为 C，参考世界（无界队列，不丢任何指令）施加的冲量为 p̂_t。
丢弃集合 D 是全部被丢指令的集合，指令 c 的冲量向量为 w_c，其 L1 大小
（权重）为 ‖w_c‖₁ = |PushX|+|PushY|。被丢冲量之和记为

```
B(D) = Σ_{c ∈ D} ‖w_c‖₁
```

定义偏差向量 Δv_t = v̂_t − v_t、Δx_t = x̂_t − x_t，偏差大小取 L1 范数。

## 2. 定理 1：偏差上界等于被丢冲量之和，与丢弃时机无关

### 2.1 冲量（速度）偏差

两世界的速度递推相减：

```
Δv_{t+1} = Δv_t + (p̂_t − p_t)
```

同帧两世界的到达指令完全相同，差恰好是本帧被丢指令的冲量之和。由望远镜求和，

```
Δv_t = Σ_{h < t} Σ_{c ∈ D_h} w_c
```

即 Δv_t 等于截至 t 帧所有被丢冲量的向量和。由三角不等式，

```
‖Δv_t‖₁ ≤ Σ_{h < t} Σ_{c ∈ D_h} ‖w_c‖₁ = B(D_{<t}) ≤ B(D)        (★)
```

**上界只依赖丢弃集合 D 的权重总和，不依赖这些指令在何时被决定丢弃。**

紧致性：当被丢冲量同号（或同向）时三角不等式取等，此时 ‖Δv_t‖₁ = B(D_{<t})，
实验中冲量偏差列与 B 列相等正是这一情形（见 `artifacts/drop/report.md`）。

### 2.2 位置偏差

展开位置递推：帧 h 施加的冲量 w 在该帧积分中进入位置一次，
之后每帧随速度再进入一次，到仿真结束帧 T−1 共参与 T−h 次位置积分。故

```
Δx_t = Σ_{h < t} (t − h) · Σ_{c ∈ D_h} w_c
```

取范数得严格加权上界与松弛上界：

```
‖Δx_t‖₁ ≤ Σ_{h < t} (t − h) · Σ_{c ∈ D_h} ‖w_c‖₁ ≤ t · B(D_{<t}) ≤ T · B(D)
```

位置偏差同样只由丢弃集合决定，与丢弃时机无关。

### 2.3 时机不变性

丢弃时机有两种：

- **Immediate（入队即丢）**：队列缓存不超过容量，每条指令到达时立即决定去留；
- **Deferred（出队时再丢）**：先缓存本帧全部到达指令，Drain 时在完整集合上做截断。

只要两种实现采用同一保留规则与同一决胜次序（权重大者优先；同权重后到者优先，
见 `queue.better`），它们面对同一帧的同一指令多重集时，选出的保留集合相同：

- Deferred 在完整多重集上选权重最大的 K 条；
- Immediate 在线维护“已见指令中权重最大的 K 条”，堆顶为其中最差者。
  新指令严格优于堆顶才替换，否则丢弃。归纳可证每一步缓存都等于当前前缀的 TopK，
  帧末即全集的 TopK。

同权重决胜取“后到者优先”是两种时机等价的关键：在线替换语义下，
先到者优先会让一条刚被保留的同权重指令无法被后来者替换，而 Deferred 在全集上
排序时会选后者，二者产生分歧；后到者优先则两路径收敛到同一集合。

因此 D 仅由（指令多重集、容量、保留规则）决定，与决策时刻无关。
代入 (★)：**两种时机的逐帧状态、哈希序列与偏差上界完全相同**。
该不变量由 `TestTimingsEquivalent`（队列层）与 `TestDriftBoundedByDroppedImpulse`
（世界层逐帧哈希比对）守护，实验中四种运行的哈希序列两两一致
（见 `artifacts/drop/hashes-*.txt`）。

## 3. 定理 2：TopK 最小化偏差上界，以及 K 与阈值 τ 的关系

### 3.1 最优性

设一帧到达 n 条指令、容量 K < n，必须丢弃 n−K 条。由定理 1，
该帧对偏差上界的贡献等于被丢指令的权重之和。问题化为：

```
min_{D ⊆ C, |D| = n−K}  Σ_{c ∈ D} ‖w_c‖₁
```

其解唯一（在决胜次序意义下）：**丢弃权重最小的 n−K 条，等价于保留权重最大的
K 条（TopK）**。证明：设任一策略保留了权重为 a 的指令却丢了权重为 b > a 的指令，
交换二者的去留，丢弃和严格下降 b−a > 0；故任何非 TopK 策略都不是最优的。

跨帧容量 K_t 可逐帧独立选取，全仿真的最优丢弃和为各帧最优值之和。
`queue.MinCapacity` 与 `queue.TailSum` 实现该计算，
`TestTopKKeepsLargest`、`TestMinCapacityBudget` 守护其正确性。

对照旧策略 TailDrop（容量满直接丢新指令）：它不看权重，重载下会丢掉后到的大
冲量指令。实验中 heavy 档同一容量下 TailDrop 的 B=1804 超出总阈值 1440，
而 TopK 的 B=1284 在阈值内。

### 3.2 保留策略与阈值的关系

设每帧阈值为 τ（允许的被丢冲量权重之和），一帧权重降序排列为
w₁ ≥ w₂ ≥ ⋯ ≥ w_n，定义尾部和 S(k) = Σ_{i=k+1}^{n} w_i（保留 k 条时的丢弃和，
S(n)=0，S(0)=Σw_i）。S(k) 关于 k 单调不增。所需最小容量为

```
K(τ) = min { k ∈ [0,n] : S(k) ≤ τ }
```

性质：

1. **充分性**：按 K(τ) 做 TopK 保留，该帧丢弃和 S(K(τ)) ≤ τ，偏差上界达标；
2. **最小性**：S(K(τ)−1) > τ（当 K(τ)>0），少保留一条必然越界，故 K(τ) 是
   满足阈值的最小容量，无冗余保留；
3. **阈值越紧容量越大**：τ 减小时 K(τ) 单调不减；τ=0 要求 K=n（全保留），
   τ ≥ Σw_i 时 K=0（全丢也达标）。

全仿真取总阈值 T·τ：只要每帧丢弃和 ≤ τ，累计 B(D) ≤ T·τ 自动成立，
再由定理 1 得全程冲量偏差 ‖Δv_t‖₁ ≤ B(D) ≤ T·τ，位置偏差 ≤ T·B(D) ≤ T²·τ。
实验即按此逐帧计算 K_t（报告附录给出 heavy 档逐帧 K(τ) 明细），
三档负载的偏差全部落在阈值内。
