# 重力 9.8 定点量化：三档分子位数 × 两条抛物轨迹

- 精确重力 g* = 49/5 = 9.8；落点容差 ε = 1/10（0.1000000）。
- 离散递推与内核一致（半隐式欧拉，SubSteps=1）：v += δg，y += v；第 n 帧位置误差 |Δy_n| = |δg|·n(n+1)/2。

## 逐档比对

- 同一帧处落点差严格正比于 |δg|：**Δ_Q8 = 256·Δ_Q16**，**Δ_Q16 = 65536·Δ_Q32**。
- 帧限 k∝1/√|δg|：位数 8→16 误差缩 256 倍、越界帧放大 √256=16 倍（16→256）；16→32 误差缩 65536 倍、越界帧放大 256 倍（256→65536）。
- 轨迹 A（n*=61）：Q8.8 Δ=1.4773437、同帧Δx=0、射程ΔX=-4.4003263 → 越界；Q16.16 Δ=0.0057709、同帧Δx=0、射程ΔX=-0.0171915 → 容差内；Q32.32 Δ=8.805655e-08、同帧Δx=0、射程ΔX=-2.623219e-07 → 容差内。
- 轨迹 B（n*=408）：Q8.8 Δ=65.1843750、同帧Δx=0、射程ΔX=-9.7462701 → 越界；Q16.16 Δ=0.2546265、同帧Δx=0、射程ΔX=-0.0380774 → 越界；Q32.32 Δ=3.885292e-06、同帧Δx=0、射程ΔX=-5.810156e-07 → 容差内。
